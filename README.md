# Pranit Deshpande | Portfolio

Personal portfolio site for Pranit Deshpande, Forward Deployed and Software Engineer.

**Live:** https://portfolio-pranit-deshpande.vercel.app

## Featured work
- [Fuse](https://github.com/pranitdeshpande98/fuse): personal AI agent (LangGraph, Telegram, Gmail and Calendar) with human approval before any action
- [Roost](https://github.com/pranitdeshpande98/roost-hr-assistant): multilingual AI HR assistant with evals and guardrails
- [Drug Interaction Checker](https://github.com/pranitdeshpande98/drug-interaction-checker): 6-agent pipeline across 2 custom MCP servers
- [Concurrent Bank Account Manager](https://github.com/pranitdeshpande98/Centralized-Multi-User-Concurrent-Bank-Account-Manager): multithreaded C++ TCP server

## Stack
Next.js 14, TypeScript, Tailwind CSS, Framer Motion, Three.js. Deployed on Vercel.

## Run locally
```bash
npm install
npm run dev
```
Site content lives in `data/index.ts`.
